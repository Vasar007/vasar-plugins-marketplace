# Create External Client Wrapper

Create external service client wrappers in `{ProjectNamespace}.Infrastructure` for microservice integration.

## Architecture Pattern

```mermaid
I{Service}{Feature}Client (Application interface)
    ↓ implemented by
{Service}{Feature}Client (Infrastructure, inherits base)
    ↓ wraps
{Service}.Client.AutoGenerated (NSwag-generated)
```

## Service Naming Conventions

These prefixes are illustrative — they are example service names from a reference implementation. Substitute your own service abbreviations when applying the pattern in your project.

| Service                           | Prefix | Example              |
|-----------------------------------|--------|----------------------|
| Infrastructure Deployment Service | `Ids`  | `IIdsSessionsClient` |
| Deployment Service                | `Ds`   | `IDsSessionsClient`  |
| Storage Management Service        | `Sms`  | `ISmsStorageClient`  |
| Data Collector Service            | `Dcs`  | `IDcsVersionClient`  |

## Files to Create

1. `Application/External/{Service}/I{Service}{Feature}Client.cs` - Interface
2. `Infrastructure/External/ApiClients/{Service}/{Feature}/{Service}{Feature}Client.cs` - Implementation

## Step 1: Interface (Application Layer)

```csharp
// Copyright (c) Vasily Vasilyev

using {Service}.Client.AutoGenerated;

namespace {ProjectNamespace}.Application.External.{Service};

/// <summary>
/// Client for {Service} {Feature} operations.
/// </summary>
public interface I{Service}{Feature}Client
{
    /// <summary>
    /// Gets {item} by ID.
    /// </summary>
    /// <param name="id">The item identifier.</param>
    /// <param name="cancellationToken">Cancellation token.</param>
    /// <returns>The {item} if found; otherwise <see langword="null"/>.</returns>
    Task<{ExternalModel}?> GetByIdAsync(Guid id, CancellationToken cancellationToken = default);

    /// <summary>
    /// Creates a new {item}.
    /// </summary>
    /// <param name="request">The creation request.</param>
    /// <param name="cancellationToken">Cancellation token.</param>
    /// <returns>Session ID for tracking the async operation.</returns>
    Task<Guid> CreateAsync({ExternalRequestModel} request, CancellationToken cancellationToken = default);
}
```

**IMPORTANT**: External clients return external service models directly. Business logic converts these to domain models as needed.

## Step 2: Implementation (Infrastructure Layer)

```csharp
// Copyright (c) Vasily Vasilyev

using Microsoft.Extensions.Logging;
using Microsoft.Extensions.Options;
using {ProjectNamespace}.Application.External.{Service};
using {ProjectNamespace}.Configuration.Options.Services;
using {ProjectNamespace}.Common.Assertions;
using {ProjectNamespace}.Framework.Configuration.Options.Net.Http;

using Rest{Abbr} = {ProjectNamespace}.{Service}.Client.AutoGenerated;

namespace {ProjectNamespace}.Infrastructure.External.ApiClients.{Service}.{Feature};

/// <inheritdoc cref="I{Service}{Feature}Client" />
internal sealed class {Service}{Feature}Client : {Service}ClientBase, I{Service}{Feature}Client
{
    private readonly Rest{Abbr}.{Feature}Client _{feature}Client;

    private {Service}{Feature}Client(
        ILogger<{Service}{Feature}Client> logger,
        IHttpClientFactory httpClientFactory,
        ServicesOptions serviceOptions,
        HttpClientOptions httpClientOptions)
        : base(
            logger: logger,
            httpClientFactory: httpClientFactory,
            serviceOptions: serviceOptions,
            httpClientOptions: httpClientOptions
        )
    {
        _{feature}Client = new(Client);
    }

    public {Service}{Feature}Client(
        ILogger<{Service}{Feature}Client> logger,
        IHttpClientFactory httpClientFactory,
        IOptionsMonitor<ServicesOptions> serviceSettings,
        IOptionsMonitor<HttpClientOptions> httpClientOptions)
        : this(
            logger: logger,
            httpClientFactory: httpClientFactory,
            serviceOptions: serviceSettings.CurrentValue,
            httpClientOptions: httpClientOptions.CurrentValue
        )
    {
    }

    /// <inheritdoc />
    public async Task<Rest{Abbr}.{ExternalModel}?> GetByIdAsync(
        Guid id,
        CancellationToken cancellationToken = default)
    {
        // Log request
        Logger.LogInformation("[{ServiceName}] Getting {Entity} by ID: {Id}", ServiceName, nameof({Entity}), id);

        var response = await _{feature}Client.GetByIdAsync(id, cancellationToken);

        // Log response
        Logger.LogInformation("[{ServiceName}] Retrieved {Entity}: {Id}", ServiceName, nameof({Entity}), response?.Id);

        return response;
    }

    /// <inheritdoc />
    public async Task<Guid> CreateAsync(
        Rest{Abbr}.{ExternalRequestModel} request,
        CancellationToken cancellationToken = default)
    {
        request.ThrowIfNull();

        // Log request
        Logger.LogInformation("[{ServiceName}] Creating {Entity} with request: {Request}", ServiceName, nameof({Entity}), request);

        var response = await _{feature}Client.CreateAsync(request, cancellationToken);

        // Log response with session ID
        Logger.LogInformation("[{ServiceName}] {Entity} creation initiated. Session ID: {SessionId}", ServiceName, nameof({Entity}), response.SessionId);

        return response.SessionId;
    }
}
```

**IMPORTANT**: External clients return external service models directly. Business logic (Application layer services) converts these to domain models based on code needs.

## Structured Logging Requirements

All methods MUST log:

### Request Logging

```csharp
Logger.LogInformation(
    "[{ServiceName}] {Action} {Entity}: {Parameters}",
    ServiceName,          // From base class
    "Getting",            // Action verb
    nameof(Entity),       // Entity type
    relevantParams        // Request parameters
);
```

### Response Logging

```csharp
Logger.LogInformation(
    "[{ServiceName}] {Result} {Entity}: {Identifier}",
    ServiceName,
    "Retrieved",          // Result description
    nameof(Entity),
    response.Id           // Result identifier
);
```

### Session ID Logging (for async operations)

```csharp
Logger.LogInformation(
    "[{ServiceName}] {Operation} initiated. Session ID: {SessionId}",
    ServiceName,
    "Creation",
    response.SessionId
);
```

## Model Conversion

**External clients return external service models directly** - they do NOT convert to domain models.

**Why?**

- External models can be converted to different domain models based on business logic needs
- Conversion logic belongs in Application layer services, not Infrastructure clients
- One external model might map to multiple domain models in different contexts

**When conversion IS needed:**

- Convert Domain → External in client wrapper (for request parameters)
- Use model converters for complex conversions (see [model-mapping](../model-mapping/SKILL.md) skill)
- Place converters in `Infrastructure/External/ApiClients/{Service}/{Feature}/Converters/`

**Example with conversion:**

```csharp
using {ProjectNamespace}.Infrastructure.External.ApiClients.{Service}.{Feature}.Converters;

public async Task<Guid> CreateAsync(
    {DomainRequest} request,  // Takes domain model
    CancellationToken cancellationToken = default)
{
    request.ThrowIfNull();
    
    // Convert Domain → External using converter
    var externalRequest = request.ToRest{Request}();
    
    var response = await _{feature}Client.CreateAsync(externalRequest, cancellationToken);
    
    return response.SessionId;  // Return primitive, not domain wrapper
}
```

## DI Registration

Register in `ServiceCollectionExtensions.cs`:

```csharp
services.AddScoped<I{Service}{Feature}Client, {Service}{Feature}Client>();
```
