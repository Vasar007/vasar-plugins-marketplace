# Controller Tests - WebApiBaseTest

Use `WebApiBaseTest` for integration tests that verify controller endpoints through HTTP requests.

## Base Class

Location: `<Project>.WebApi.Tests.ForTests.WebApiBaseTest` (per-service — substitute your repo's WebApi tests namespace)

Inherits from: `BaseMockTest` (provides `Fixture` for mocking)

Provides:

- `_webApplicationFactory` - Test host factory
- `_webApplicationClient` - Configured HttpClient
- `ExternalServicesMock` - Mock for external services
- Automatic database cleanup in `[SetUp]`

## Complete Example

```csharp
// Copyright (c) Vasily Vasilyev

using MyApp.Resources.Properties;
using MyApp.Tests.Common.Helpers.Generators.Workload.Tenants;
using MyApp.Tests.Common.Helpers.Persistence.Workload.Tenants;
using MyApp.WebApi.Converters.Workload.Tenants;
using MyApp.WebApi.Tests.ForTests;
using MyApp.WebApi.Tests.ForTests.FluentAssertions;
using MyApp.Framework.Basic.Strings;

using Rest = MyApp.WebApi.Tests.AutoGenerated;

namespace MyApp.WebApi.Tests.Controllers.Workload.Tenants;

[TestFixture]
[Parallelizable(ParallelScope.Fixtures)]
public sealed class TenantsControllerTests : WebApiBaseTest
{
    private readonly Rest.TenantsClient _tenantsClient;
    private readonly TenantGenerator _tenantGenerator;

    public TenantsControllerTests()
    {
        // Create typed client using generated NSwag client
        _tenantsClient = new(_webApplicationClient);
        _tenantGenerator = new TenantGenerator();
    }

    [Test]
    public async Task GetTenantsAsync_ReturnsOk_WhenTenantsExist()
    {
        // Arrange.
        await using var scope = _webApplicationFactory.Services.CreateAsyncScope();
        var itemBuilder = CreateTestTenantRepository(scope);
        var expectedPage = await itemBuilder.AddTenantsPageAsync(count: 5);
        await itemBuilder.SaveChangesAsync();

        // Act.
        var actualPage = await _tenantsClient.GetTenantsAsync(
            offset: 0,
            limit: 10,
            regionId: null,
            status: null,
            organizationId: null,
            createdAfter: null,
            createdBefore: null,
            cancellationToken: CancellationToken.None
        );

        // Assert.
        actualPage.Should().NotBeNull();
        actualPage.TotalCount.Should().Be(expectedPage.TotalCount);
        actualPage.Items.Should().HaveSameCount(expectedPage.Items);
    }

    [Test]
    public async Task GetTenantsAsync_ReturnsOk_WhenNoTenantsFound()
    {
        // Arrange - empty database (cleared in SetUp)

        // Act.
        var actualPage = await _tenantsClient.GetTenantsAsync(
            offset: 0,
            limit: 10,
            regionId: null,
            status: null,
            organizationId: null,
            createdAfter: null,
            createdBefore: null,
            cancellationToken: CancellationToken.None
        );

        // Assert.
        actualPage.Should().NotBeNull();
        actualPage.TotalCount.Should().Be(0);
        actualPage.Items.Should().BeEmpty();
    }

    [Test]
    public async Task GetTenantAsync_ReturnsNotFound_WhenTenantDoesNotExist()
    {
        // Arrange.
        var tenantId = _tenantGenerator.GenerateTenantId();

        // Act.
        var act = () => _tenantsClient.GetTenantAsync(tenantId.Value);

        // Assert.
        await act.CustomShould().ContainNotFoundError(
            StringResources.NotFoundTenantMessage.SafeFormat(tenantId)
        );
    }

    [Test]
    public async Task GetTenantAsync_ReturnsBadRequest_WhenInvalidTenantId()
    {
        // Arrange.
        var invalidTenantId = TenantId.Empty;

        // Act.
        var act = () => _tenantsClient.GetTenantAsync(invalidTenantId.Value);

        // Assert.
        await act.CustomShould().ContainBadRequest(
            StringResources.InvalidTenantIdMessage.SafeFormat(invalidTenantId)
        );
    }

    [Test]
    public async Task ProvisionTenantAsync_ReturnsSessionLink()
    {
        // Arrange.
        var request = CreateTestProvisionRequest();

        // Act.
        var sessionLink = await _tenantsClient.ProvisionTenantAsync(request);

        // Assert.
        sessionLink.Should().NotBeNull();
        sessionLink.SessionId.Should().NotBeEmpty();
    }

    // ============ Private helpers ============

    private TestTenantRepository CreateTestTenantRepository(AsyncServiceScope scope)
    {
        return new TestTenantRepository(scope.ServiceProvider);
    }

    private static Rest.TenantProvisionRequest CreateTestProvisionRequest()
    {
        return new Rest.TenantProvisionRequest
        {
            Name = "test-tenant",
            RegionId = "us-east-1",
            OrganizationId = Guid.NewGuid(),
        };
    }
}
```

## Test Patterns

### 1. Success Case - Resource Exists

```csharp
[Test]
public async Task GetResource_ReturnsOk_WhenExists()
{
    // Arrange.
    await using var scope = _webApplicationFactory.Services.CreateAsyncScope();
    var builder = CreateTestRepository(scope);
    var expected = await builder.AddResourceAsync();
    await builder.SaveChangesAsync();

    // Act.
    var actual = await _client.GetResourceAsync(expected.Id.Value);

    // Assert.
    actual.Should().NotBeNull();
    actual.Id.Should().Be(expected.Id.Value);
}
```

### 2. Not Found Case

```csharp
[Test]
public async Task GetResource_ReturnsNotFound_WhenDoesNotExist()
{
    // Arrange.
    var resourceId = _generator.GenerateResourceId();

    // Act.
    var act = () => _client.GetResourceAsync(resourceId.Value);

    // Assert.
    await act.CustomShould().ContainNotFoundError(
        StringResources.NotFoundResourceMessage.SafeFormat(resourceId)
    );
}
```

### 3. Bad Request Case

```csharp
[Test]
public async Task GetResource_ReturnsBadRequest_WhenInvalidId()
{
    // Arrange.
    var invalidId = ResourceId.Empty;

    // Act.
    var act = () => _client.GetResourceAsync(invalidId.Value);

    // Assert.
    await act.CustomShould().ContainBadRequest(
        StringResources.InvalidResourceIdMessage.SafeFormat(invalidId)
    );
}
```

### 4. Parameterized Tests

```csharp
[Test]
[TestCase(null)]
[TestCase(false)]
[TestCase(true)]
public async Task DeleteResource_ReturnsOk(Boolean? force)
{
    // Arrange.
    await using var scope = _webApplicationFactory.Services.CreateAsyncScope();
    var builder = CreateTestRepository(scope);
    var resource = await builder.AddResourceAsync();
    await builder.SaveChangesAsync();

    // Act.
    var sessionLink = await _client.DeleteResourceAsync(resource.Id.Value, force);

    // Assert.
    sessionLink.Should().NotBeNull();
    sessionLink.SessionId.Should().NotBeEmpty();
}
```

## FluentAssertions Extensions

Use custom assertion extensions for HTTP responses:

```csharp
// Check for NotFound with specific message
await act.CustomShould().ContainNotFoundError(expectedMessage);

// Check for BadRequest with specific message
await act.CustomShould().ContainBadRequest(expectedMessage);

// Check for Conflict
await act.CustomShould().ContainConflictError(expectedMessage);
```

## Test Data Setup

Use persistence helpers to set up database state:

```csharp
await using var scope = _webApplicationFactory.Services.CreateAsyncScope();
var builder = CreateTestTenantRepository(scope);

// Add single item
var item = await builder.AddTenantAsync();

// Add page of items
var page = await builder.AddTenantsPageAsync(count: 10);

// Don't forget to save
await builder.SaveChangesAsync();
```

## External Service Mocking

Configure external service responses via `ExternalServicesMock`:

```csharp
[Test]
public async Task ProvisionTenant_WhenIdsReturnsError_ReturnsBadGateway()
{
    // Arrange.
    ExternalServicesMock.IdsClient
        .GetOrganizationAsync(Arg.Any<Guid>(), Arg.Any<CancellationToken>())
        .ThrowsAsync(new HttpRequestException("IDS unavailable"));

    var request = CreateTestProvisionRequest();

    // Act.
    var act = () => _tenantsClient.ProvisionTenantAsync(request);

    // Assert.
    await act.CustomShould().ContainBadGatewayError("IDS");
}
```

## Key Points

1. **NSwag clients** - Use generated REST clients from `AutoGenerated/` namespace

2. **Database cleanup** - `[SetUp]` automatically clears database before each test

3. **Scope management** - Use `await using var scope` for DI scope access

4. **Custom assertions** - Use `.CustomShould()` for HTTP-specific assertions

5. **Generators** - Use test generators for creating valid request data

6. **External mocks** - Configure `ExternalServicesMock` for external service behavior
