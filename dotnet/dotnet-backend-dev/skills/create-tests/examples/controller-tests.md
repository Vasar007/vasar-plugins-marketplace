# Controller Tests - WebApiBaseTest

Use `WebApiBaseTest` for integration tests that verify controller endpoints through HTTP requests.

## Base Class

Location: `<Project>.WebApi.Tests.ForTests.WebApiBaseTest` (one for each service: use the WebApi tests namespace of your repository)

Inherits from: `BaseMockTest` (provides `Fixture` for mocking)

Provides:

- `_webApplicationFactory` - Test host factory
- `_webApplicationClient` - Configured HttpClient
- `ExternalServicesMock` - Mock for external services
- Automatic database cleanup in `[SetUp]`

## Structure

```text
WebApi.Tests/
├── ForTests/

```

## Complete Example

```csharp
// Copyright (c) Vasily Vasilyev

using MyApp.Resources.Properties;
using MyApp.Tests.Common.Helpers.Generators.Sales.Customers;
using MyApp.Tests.Common.Helpers.Persistence.Sales.Customers;
using MyApp.WebApi.Converters.Sales.Customers;
using MyApp.WebApi.Tests.ForTests;
using MyApp.WebApi.Tests.ForTests.FluentAssertions;
using MyApp.Framework.Basic.Strings;

using Rest = MyApp.WebApi.Tests.AutoGenerated;

namespace MyApp.WebApi.Tests.Controllers.Sales.Customers;

[TestFixture]
[Parallelizable(ParallelScope.Fixtures)]
public sealed class CustomersControllerTests : WebApiBaseTest
{
    private readonly Rest.CustomersClient _customersClient;
    private readonly CustomerGenerator _customerGenerator;

    public CustomersControllerTests()
    {
        // Create typed client using generated NSwag client
        _customersClient = new(_webApplicationClient);
        _customerGenerator = new CustomerGenerator();
    }

    [Test]
    public async Task GetCustomersAsync_ReturnsOk_WhenCustomersExist()
    {
        // Arrange.
        await using var scope = _webApplicationFactory.Services.CreateAsyncScope();
        var itemBuilder = CreateTestCustomerRepository(scope);
        var expectedPage = await itemBuilder.AddCustomersPageAsync(count: 5);
        await itemBuilder.SaveChangesAsync();

        // Act.
        var actualPage = await _customersClient.GetCustomersAsync(
            offset: 0,
            limit: 10,
            countryCode: null,
            status: null,
            storeId: null,
            createdAfter: null,
            createdBefore: null,
            cancellationToken: CancellationToken.None
        );

        // Assert.
        actualPage.Should().NotBeNull();
        actualPage.TotalCount.Should().Be(expectedPage.TotalCount);
        actualPage.Items.Should().HaveSameCount(expectedPage.Items);
    }

    [Test]
    public async Task GetCustomersAsync_ReturnsOk_WhenNoCustomersFound()
    {
        // Arrange - empty database (cleared in SetUp)

        // Act.
        var actualPage = await _customersClient.GetCustomersAsync(
            offset: 0,
            limit: 10,
            countryCode: null,
            status: null,
            storeId: null,
            createdAfter: null,
            createdBefore: null,
            cancellationToken: CancellationToken.None
        );

        // Assert.
        actualPage.Should().NotBeNull();
        actualPage.TotalCount.Should().Be(0);
        actualPage.Items.Should().BeEmpty();
    }

    [Test]
    public async Task GetCustomerAsync_ReturnsNotFound_WhenCustomerDoesNotExist()
    {
        // Arrange.
        var customerId = GenerateCustomerId();

        // Act.
        var act = () => _customersClient.GetCustomerAsync(customerId.Value);

        // Assert.
        await act.CustomShould().ContainNotFoundError(
            StringResources.NotFoundCustomerMessage.SafeFormat(customerId)
        );
    }

    [Test]
    public async Task GetCustomerAsync_ReturnsBadRequest_WhenInvalidCustomerId()
    {
        // Arrange.
        var invalidCustomerId = CustomerId.Empty;

        // Act.
        var act = () => _customersClient.GetCustomerAsync(invalidCustomerId.Value);

        // Assert.
        await act.CustomShould().ContainBadRequest(
            StringResources.InvalidCustomerIdMessage.SafeFormat(invalidCustomerId)
        );
    }

    [Test]
    public async Task RegisterCustomerAsync_ReturnsSessionLink()
    {
        // Arrange.
        var request = CreateTestRegistrationRequest();

        // Act.
        var sessionLink = await _customersClient.RegisterCustomerAsync(request);

        // Assert.
        sessionLink.Should().NotBeNull();
        sessionLink.SessionId.Should().NotBeEmpty();
    }

    // ============ Private helpers ============

    private TestCustomerRepository CreateTestCustomerRepository(AsyncServiceScope scope)
    {
        return new TestCustomerRepository(scope.ServiceProvider);
    }

    private CustomerId GenerateCustomerId()
    {
        return _customerGenerator.GenerateCustomerId();
    }

    private static Rest.CustomerRegistrationRequest CreateTestRegistrationRequest()
    {
        return new Rest.CustomerRegistrationRequest
        {
            Name = "test-customer",
            CountryCode = "US",
            StoreId = Guid.NewGuid(),
        };
    }
}
```

## Test Patterns

### 1. Success Case - Resource Exists

```csharp
[Test]
public async Task GetResource_ReturnsOk_WhenExists()
{
    // Arrange.
    await using var scope = _webApplicationFactory.Services.CreateAsyncScope();
    var builder = CreateTestRepository(scope);
    var expected = await builder.AddResourceAsync();
    await builder.SaveChangesAsync();

    // Act.
    var actual = await _client.GetResourceAsync(expected.Id.Value);

    // Assert.
    actual.Should().NotBeNull();
    actual.Id.Should().Be(expected.Id.Value);
}
```

### 2. Not Found Case

```csharp
[Test]
public async Task GetResource_ReturnsNotFound_WhenDoesNotExist()
{
    // Arrange.
    var resourceId = GenerateResourceId();

    // Act.
    var act = () => _client.GetResourceAsync(resourceId.Value);

    // Assert.
    await act.CustomShould().ContainNotFoundError(
        StringResources.NotFoundResourceMessage.SafeFormat(resourceId)
    );
}
```

### 3. Bad Request Case

```csharp
[Test]
public async Task GetResource_ReturnsBadRequest_WhenInvalidId()
{
    // Arrange.
    var invalidId = ResourceId.Empty;

    // Act.
    var act = () => _client.GetResourceAsync(invalidId.Value);

    // Assert.
    await act.CustomShould().ContainBadRequest(
        StringResources.InvalidResourceIdMessage.SafeFormat(invalidId)
    );
}
```

### 4. Parameterized Tests

```csharp
[Test]
[TestCase(null)]
[TestCase(false)]
[TestCase(true)]
public async Task DeleteResource_ReturnsOk(Boolean? force)
{
    // Arrange.
    await using var scope = _webApplicationFactory.Services.CreateAsyncScope();
    var builder = CreateTestRepository(scope);
    var resource = await builder.AddResourceAsync();
    await builder.SaveChangesAsync();

    // Act.
    var sessionLink = await _client.DeleteResourceAsync(resource.Id.Value, force);

    // Assert.
    sessionLink.Should().NotBeNull();
    sessionLink.SessionId.Should().NotBeEmpty();
}
```

## FluentAssertions Extensions

Use custom assertion extensions for HTTP responses:

```csharp
// Check for NotFound with specific message
await act.CustomShould().ContainNotFoundError(expectedMessage);

// Check for BadRequest with specific message
await act.CustomShould().ContainBadRequest(expectedMessage);

// Check for Conflict
await act.CustomShould().ContainConflictError(expectedMessage);
```

## Test Data Setup

Use persistence helpers to set up database state:

```csharp
await using var scope = _webApplicationFactory.Services.CreateAsyncScope();
var builder = CreateTestCustomerRepository(scope);

// Add single item
var item = await builder.AddCustomerAsync();

// Add page of items
var page = await builder.AddCustomersPageAsync(count: 10);

// Don't forget to save
await builder.SaveChangesAsync();
```

## External Service Mocking

Configure external service responses on `ExternalServicesMock` in the test case. This is the one exception to the no-post-setup rule (rule 3 of [SKILL.md](../SKILL.md)). `WebApiBaseTest` injects this mock into the ASP.NET pipeline, where it intercepts the calls of the running app to external services. So the test case sets up the behavior that it needs after the setup:

```csharp
[Test]
public async Task RegisterCustomer_WhenLoyaltyServiceReturnsError_ReturnsBadGateway()
{
    // Arrange.
    ExternalServicesMock.LoyaltyClient.GetMemberAsync(Arg.Any<Guid>(), Arg.Any<CancellationToken>()).ThrowsAsync(new HttpRequestException("loyalty service unavailable"));

    var request = CreateTestRegistrationRequest();

    // Act.
    var act = () => _customersClient.RegisterCustomerAsync(request);

    // Assert.
    await act.CustomShould().ContainBadGatewayError("loyalty service");
}
```

## Key Points

1. **NSwag clients**: Use generated REST clients from `AutoGenerated/` namespace

2. **Database cleanup**: `[SetUp]` automatically clears database before each test

3. **Scope management**: Use `await using var scope` for DI scope access

4. **Custom assertions**: Use `.CustomShould()` for HTTP-specific assertions

5. **Generators**: Use test generators for creating valid request data

6. **External mocks**: Configure external service behavior on `ExternalServicesMock` in the test case. This is the one exception to the no-post-setup rule.
