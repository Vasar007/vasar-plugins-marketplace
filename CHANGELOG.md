### Added

- Initial marketplace layout with three plugins:
  - `dev-essentials` — composer agents, workflow commands, and generic skills (markdown, XML docs, git worktrees, PR review comments, general conventions, feature pipeline).
  - `dotnet-backend-dev` — .NET / Clean Architecture / DDD / EF Core / OpenAPI skills plus a backend conventions hub.
  - `gop-pipeline` — Git Operations Pipeline workflow (plan → implement → build → test → validate → commit) with five parallel validator subagents.
- MIT license, README with install instructions, plugin/skill authoring reference, root `CLAUDE.md`.
